# Activity A3 — Select and Apply Quality Tools

**Course:** ISO 9001:2015 Quality Management System (C239)  
**Objective:** Choose quality tools that fit the question, data type and customer segment.

## Scenario

LPC has 60 recent complaints from three customer segments. The descriptions are inconsistent and teams jump directly to favourite solutions.

LionCity Precision Components Pte Ltd (LPC) is a singapore sme with 85 employees producing precision aluminium components for commercial equipment. Three regional equipment makers account for 72% of revenue; one now requires ISO 9001 certification from key suppliers.

## Task and expected output

Use check sheets, Pareto analysis and cause-and-effect analysis to prioritise LPC's customer complaints.

Produce: **A coded complaint check sheet, Pareto chart and evidence-led cause hypothesis.**

## Decision questions

1. Which tool answers 'what happens most often' and which explores 'why might it happen'?
2. Do the priorities change by customer segment or product family?
3. Which possible cause needs verification before it can be treated as root cause?

## Detailed procedure

1. Code raw complaint descriptions into consistent categories.
2. Validate category definitions on a sample with a partner.
3. Build a frequency table and Pareto chart with cumulative percentage.
4. Stratify the vital categories by customer segment.
5. Build a fishbone hypothesis and specify evidence needed to test each major branch.

## Acceptance checklist

- [ ] The Pareto chart reconciles to the complaint total and the selected cause hypothesis is explicitly labelled for verification.
- [ ] Claims are traceable to the supplied evidence.
- [ ] Assumptions and missing evidence are labelled.
- [ ] The workbook contains an owner and next decision where applicable.
- [ ] A peer challenge and response are recorded.

## Facilitator debrief

Ask each team to defend one priority, control or conclusion using objective evidence. Probe what would change their decision. Connect the work to PDCA and the applicable QMS process rather than asking learners to recite clause text.
