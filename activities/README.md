# ISO 9001 Course Activities

Eight connected activities for **ISO 9001:2015 Quality Management System** (C239). Each folder includes a detailed Markdown procedure, printable PDF scenario/checklist and editable Excel workbook.

- [Activity A1 — Diagnose Quality Gaps from Evidence](activity-01-quality-gap-diagnosis/README.md)
- [Activity A2 — Map and Improve the Order-to-Delivery Process](activity-02-order-to-delivery-process/README.md)
- [Activity A3 — Select and Apply Quality Tools](activity-03-quality-tools/README.md)
- [Activity A4 — Set Quality Objectives and KPIs](activity-04-quality-objectives-kpis/README.md)
- [Activity A5 — Evaluate a Process Against QMS Requirements](activity-05-qms-process-evaluation/README.md)
- [Activity A6 — Conduct an Internal Audit Simulation](activity-06-internal-audit-simulation/README.md)
- [Activity A7 — Follow Up a Nonconformity and Corrective Action](activity-07-nonconformity-corrective-action/README.md)
- [Activity A8 — Document the Continual Improvement Report](activity-08-continual-improvement-report/README.md)

## Learning sequence

The activities share the fictional LPC case: diagnose gaps, map the process, select tools, establish measures, evaluate requirements, audit evidence, close a nonconformity and document the resulting improvement.
