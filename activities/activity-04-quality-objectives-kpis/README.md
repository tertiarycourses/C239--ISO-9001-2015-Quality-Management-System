# Activity A4 — Set Quality Objectives and KPIs

**Course:** ISO 9001:2015 Quality Management System (C239)  
**Objective:** Set relevant metrics and KPIs for process monitoring and decision-making.

## Scenario

LPC's current dashboard lists activity counts but no targets, owners, decision thresholds or links to customer outcomes.

LionCity Precision Components Pte Ltd (LPC) is a singapore sme with 85 employees producing precision aluminium components for commercial equipment. Three regional equipment makers account for 72% of revenue; one now requires ISO 9001 certification from key suppliers.

## Task and expected output

Translate LPC's quality policy into SMART objectives, operational measures and a review cadence.

Produce: **A KPI dictionary and dynamic dashboard with targets, formulas, status signals and ownership.**

## Decision questions

1. Which measures are leading, lagging, effectiveness or efficiency indicators?
2. What behaviour could each KPI unintentionally encourage?
3. What decision will management make when a KPI crosses its threshold?

## Detailed procedure

1. Rewrite two broad intentions as SMART quality objectives.
2. Define each KPI's purpose, formula, unit, data source, owner and frequency.
3. Enter the supplied monthly data and verify formula-driven results.
4. Set target and escalation thresholds with documented rationale.
5. Review the dashboard and write the decision triggered by each red status.

## Acceptance checklist

- [ ] Every KPI has an auditable formula, source, owner, target and defined management response; workbook formulas return no errors.
- [ ] Claims are traceable to the supplied evidence.
- [ ] Assumptions and missing evidence are labelled.
- [ ] The workbook contains an owner and next decision where applicable.
- [ ] A peer challenge and response are recorded.

## Facilitator debrief

Ask each team to defend one priority, control or conclusion using objective evidence. Probe what would change their decision. Connect the work to PDCA and the applicable QMS process rather than asking learners to recite clause text.
